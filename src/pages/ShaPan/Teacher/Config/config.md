# 配置参数
## 全局配置
1. 市场总客户基数 100万人 

2. 三大产品客群占比 
 + 贷款意向客户占比 0.5  100 * 0.5 = 50万人
 + 保险意向客户占比 0.3  100 * 0.3 = 30万人
 + 基金意向客户占比 0.2  100 * 0.2 = 20万人

3. 宏观环境参数配置
 + 经济总体系数 0.5 - 1.5 基准值 1 （小于1，代表萧条，大于1，代表繁荣）整体全品类成交倍率，越高全市场转化率提升
 + 货币政策系数 0.5 - 1.5 基准值 1 影响贷款市场：系数高银行放款容易，贷款客户更容易成交
 + 行业监管系数 0.5 - 1.5 基准值 1 保险、基金：监管严（系数低），客户投保 / 申购更谨慎
 + 居民消费意愿系数 0.5 - 1.5 影响车贷、消费贷、保险等产品
 + 资本市场行情系数 0.5 - 1.5 只影响基金成交，牛市＞1、熊市＜1

4. 最终宏观环境系数计算：
+ 经济总体系数 * 货币政策系数 * 行业监管系数 * 居民消费意愿系数 * 资本市场行情系数

  + A信用占比 0.2  50 * 0.2 = 10万人

  + D信用占比 0.1  50 * 0.1 = 5万人

  + 中收入占比 0.6  50 * 0.6 = 30万人
  + 高收入占比 0.2  50 * 0.2 = 10万人

 + 贷款细分偏好配置（只有贷款意向客户才需要）
